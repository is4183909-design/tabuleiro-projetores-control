# Painel de controlo · Tabuleiro de chão

## Ficheiro pronto a abrir

Abra `painel-tabuleiro.html` no navegador. É uma aplicação autónoma, sem instalar dependências e sem servidor para o modo de simulação.

Inclui painel de 4 projetores simulados, tabuleiro interativo, simulação de sensores, controlos de partida, Cobras e escadas, corrida de percurso, corrida Ludo simplificada, registo de eventos e armazenamento local no navegador.

## ZIP

Descarregue o projeto através do botão **Code → Download ZIP** no repositório, ou use o link de arquivo ZIP da branch publicada.

## Limites de hardware

O ficheiro fornecido é uma simulação e não comanda projetores físicos nem recebe eventos de sensores reais. Para integração é necessário conhecer os modelos e protocolos de hardware. A paragem de emergência deve ser um circuito físico independente do software.
